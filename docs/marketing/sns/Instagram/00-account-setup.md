# Instagram アカウント初期設定

作成日: 2026-04-06

## 1. クリエイターアカウントへの切り替え

設定 → アカウントの種類とツール → プロフェッショナルアカウントに切り替え → **クリエイター** → カテゴリ「Shopping & Retail」

## 2. プロフィール設定

### ユーザーネーム

```
@animehubs_swe
```

### 表示名

```
AnimeHubs 🇯🇵→🇸🇪 Uppsala
```

「何者か」が一瞬でわかる。検索にも引っかかりやすい。

### Bio（自己紹介）

```
Anime figures, straight from Japan 🇯🇵→🇸🇪
Two friends in Uppsala · here since Dec 2025
A piece of Japan on your Nordic shelf ✨
Pickup in Uppsala 📍 Shop ↓
```

4行。狙い:
- `Two friends in Uppsala` で 2 人運営を明示（個人感 + 親近感）
- `since Dec 2025` で「移住して新参・5ヶ月目」を出す（学び中の親近感）
- `Nordic shelf` でポジショニング（スウェーデン文化×日本のアニメ）を Bio に埋め込む
- `Pickup in Uppsala` は他店にない強み

メンバー構成（公開度の方針）:
- **Tomo**: 顔出しOK・公開上の語り手（"I" を使う場面の主体）
- **友人**: 同じ Uppsala 在住の日本人・**顔出しNG**・名前は出さない（"a friend" で言及）
- 投稿の「we / us」= 2人体制、「I」= Tomo 個人視点

### プロフィールリンク

```
https://anime-hubs.com/en
```

※ 将来的にLinktreeやlit.linkを検討するが、今はサイト直リンクで十分。

### プロフィール画像

ロゴまたはブランドマーク。
小さい丸の中で視認できるデザインであること。文字だけのロゴはNG（読めない）。

## 3. ハイライト設計（ストーリーズのまとめ）

プロフィール訪問者が「何のアカウントか」を理解するための導線。
初期は以下の4つを用意する。カバー画像はCanvaで統一デザインにする。

| ハイライト名 | 内容 | カバーアイコン案 |
|-------------|------|-----------------|
| `NEW` | 新着商品の紹介 | 📦 or ✨ |
| `FROM JAPAN` | 仕入れ〜到着の裏側 | 🇯🇵 |
| `REVIEWS` | 購入者の声・UGC | ⭐ |
| `PICKUP` | ローカルピックアップの説明 | 📍 |

※ REVIEWSとPICKUPは最初は空でもOK。枠だけ作っておく。

---

## 4. Canvaでのブランドキット設定

Canva（無料版）でブランドカラーとフォントを登録しておく。

| 要素 | 設定値 |
|------|--------|
| プライマリカラー | `#0a0a0a`（サイトのヘッダー色） |
| セカンダリカラー | `#fafafa`（サイトの背景色） |
| アクセント | `#262626` |
| フォント（見出し） | Inter Bold |
| フォント（本文） | Inter Regular |

ストーリーズのテンプレート、告知画像などすべてこのキットで作る → フィード全体の統一感。
