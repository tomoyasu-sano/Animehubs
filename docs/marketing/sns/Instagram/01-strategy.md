## ポジショニングの核

> **「スウェーデンの部屋に、日本のアニメを」**

スウェーデンには「mys / hygge」＝部屋を整えてくつろぐ文化がある。
キャンドル、棚インテリア、暖色の照明、季節の移ろいに敏感。
そこに「アニメフィギュア」を置く文化はまだ薄い。

AnimeHubs はこの空白を埋める。「アニメショップ」ではなく「Nordic shelf にアニメを置くライフスタイル」を提示する。

すべての投稿は、商品単体ではなく **「部屋・暮らしの中のアニメ」** という世界観を裏地に置く。

## ペルソナ

| 項目 | 設定 | 投稿への反映 |
|---|---|---|
| チーム | **2人プロジェクト**（Tomo + 友人、ともに Uppsala 在住の日本人） | 「we / us」を活動主語に |
| 公開上の語り手 | **Tomo**（顔出しOK） | "I'm Tomo" の自己紹介・顔出し投稿 |
| 友人 | **顔出しNG**・名前出さない | "a friend" で言及。写真には登場させない |
| 出身 | 2人とも日本 | 日本語ワンポイント混ぜが自然 |
| 居住 | Uppsala, Sweden（**2025年12月移住**） | 「5ヶ月目」「最初の春」など時系列ネタ |
| 役割分担 | 特になし、一緒にやるスタイル | 「分業」を強調しない、フラットな関係性 |
| 動機 | スウェーデンでアニメを身近にしたい | 売り込まない、共有する姿勢 |
| 英語 | ビジネスレベル | 投稿の主言語、自然な表現 |
| スウェーデン語 | **初心者（A1相当）** | 挨拶・1単語のみ、優しめ |
| 日本語 | ネイティブ | 漢字表記・感嘆詞をたまに |

**完璧を演じない。**「移住5ヶ月目の日本人2人が手探りでやっている」ことが信頼と親近感の源。

### 主語の使い分け（重要）

| 主語 | 使う場面 |
|---|---|
| `we / us / our` | 活動全般（仕入れ・梱包・運営）。AnimeHubs を主語にする時 |
| `I` | Tomo 個人の視点（「移住して感じたこと」「好きなアニメ」など） |
| `my friend` | 友人に言及する時（名前は出さない） |
| `the two of us` | 2人体制を強調したい時（節目の投稿） |

例:
- "We just shipped 3 orders this week 📦" — 活動として
- "I'm Tomo, the face you see around here" — 個人として
- "My friend handles the camera-shy side of things" — 友人言及

スウェーデン語は使う場面と使わない場面を分ける:
- 使う: `Hej!` `Tack!` `Mysig kväll` `Härligt!` `Trevlig helg!` 程度
- 使わない: 文法を組み立てる必要がある文章

詳細は `03-pipeline-and-voice.md` のスウェーデン語フレーズ集。

## ブランドボイス（投稿の「声」）

### トーン

| ○ こう見せる | × こうならない |
|---|---|
| カジュアル、フレンドリー | 企業的、冷たい |
| 短い文。余白がある | 長文。情報詰め込み |
| 個人的なエピソードを添える | 商品スペックの羅列 |
| たまに日本語・スウェーデン語を1単語混ぜる | 全文日本語 / 全文スウェーデン語 |
| 「自分もアニメ好きの一人」として語る | 「お店がお客様に語りかける」 |

### 言語ルール

- キャプションは英語がベース（ターゲットの共通語、ビジネスレベル）
- 完璧な英語より少しカジュアル（口語表現を混ぜる: `'cause` `kinda` 等）
- 日本語ワンポイント: キャラ名の漢字表記、感嘆詞（sugoi, kawaii）を時々
  - 例: `Tanjiro (竈門炭治郎) finally arrived 🇯🇵`
- スウェーデン語: 単語混ぜのみ（`Hej` `Tack` `Mysig` 等）
- 絵文字: 1投稿に2-3個まで

### キャプションの「型」

```
[短いフック（1行で興味を引く）]

[2-3行の本文（エピソードや感想）]

[CTA（質問 or 誘導）]

[ハッシュタグブロック]
```

例:
```
This one came all the way from a small shop in Akihabara.

My friend found it on a shelf between hundreds of figures
— the box was a little beat up but the figure inside? Perfect.

What's your favorite Demon Slayer character? 👇

#animehubs #animesverige ...
```

## 商品タイプ別の見せ方

### 開封済みフィギュア

ライフスタイル撮影の主力。棚・窓辺に飾って「暮らしの中のアニメ」を表現。

- 棚ディスプレイ（小物と組み合わせ）
- 手持ち写真
- ディテール寄り
- ビフォーアフター（2枚カルーセル）

### 未開封フィギュア

「パッケージの美しさ」「コレクター価値」を前面に。

- 箱正面のパッケージアート
- 封印シール・未開封の証拠
- 複数の未開封品を並べた写真
- ストーリーズ投票「Open or keep sealed? 🤔」

| 形式 | 方針 |
|---|---|
| 顔写真 | OK。ストーリーズや「自分+商品」の写真で使う |

「顔が見える日本人がスウェーデンでやっている」= 最強の信頼要素。写真での顔出しは積極的に使う。

## 日本の仕入れパートナーへの撮影指示（次回仕入れ時）

友人がすでに購入済み。次回仕入れ時に以下を依頼する。

```
【撮影お願い】

以下の動画/写真を撮ってほしい:

1. お店の外観（看板が映るように）— 5秒の動画
2. 店内の棚（フィギュアが並んでいる様子）— ゆっくりパンする動画10秒
3. 商品を手に取る瞬間 — 5秒の動画
4. レジで購入する瞬間 — 5秒の動画
5. 購入品をテーブルに並べた写真 — 真上から1枚

撮影のコツ:
- 縦撮り（スマホ縦のまま）
- 手ブレしないようにゆっくり
- 店名・住所が映り込んでもOK（むしろ映ってほしい）
- 自然な感じで、演出しなくていい
```

それまでの「From Japan」コンテンツの代替:
- 手元にある日本語の箱・ラベル・梱包材を活用した写真
- 「From Japan」のテキストオーバーレイ + 商品の箱写真
- 商品の日本語ラベル寄り写真
- 梱包作業の様子（自分が発送準備する手元動画）
